# 시약 가격 자료 출처 조사

조사일 2026-11-04. 문서 조사만 했고 내려받기나 계정 생성은 하지 않았다.

## 결론

무료로 바로 받아 쓸 수 있는 공개 가격 자료는 찾지 못했다. 가격을 쓰려면 공급사에
계정이나 견적을 신청해야 한다.

## 출처별 상태

| 출처 | 가격 | 자동 조회 | 판정 |
|---|---|---|---|
| Enamine 카탈로그 SDF | 공식 페이지에 가격 언급 없음. 가격은 EnamineStore에서 보라고 안내 | SDF 내려받기만 | 견적 요청 필요 |
| Mcule | 상품 페이지에 수량별 가격 있음 | 무료 계정 후 토큰을 메일로 신청 | 신청 필요 |
| MolPort | 미확인 | API v3.0 존재, 계정 또는 API 키 필요 | 신청 필요 |
| eMolecules | 자체 플랫폼에는 있음 | 공개 자료 확인 실패 | 신청 필요 |
| ZINC20 / ZINC22 | 가격 없음. 구매 가능 단계만 있음 | tranche 내려받기, CartBlanche22 API | 가격용으로 사용 불가 |
| Sigma-Aldrich, TCI, Alfa | 웹에 표시됨 | 공개 API 없음 | 자동 수집은 권장하지 않음 |

## 조사의 한계

약관 전문을 직접 읽은 곳이 한 군데도 없다. MolPort 문서는 403, Mcule API 페이지는 404,
Sigma 약관은 시간 초과, ZINC CartBlanche22는 연결 거부였다. 따라서 "약관상 허용 여부"는
모두 미확인으로 두어야 한다.

## 논문이 쓰는 가격 출처

- Badowski 외 2019 (Chematica 계열)은 Sigma-Aldrich 카탈로그 20만 개 이상을 그램 단위로
  표준화해 썼다. 그 가격 자료가 공개 배포됐다는 근거는 찾지 못했다.
  https://pmc.ncbi.nlm.nih.gov/articles/PMC6495691
- AiZynthFinder에는 전구체 가격 합계 스코어러와 Badowski식 경로 비용 스코어러가 있다.
  가격 자료는 사용자가 직접 넣는 구조다.
  https://molecularai.github.io/aizynthfinder/scoring.html

즉 가격 계산 방법론은 공개돼 있으나 가격 자료 자체는 각자 구해야 한다.

## 3단계에서 고를 선택지

1. 재윤의 기존 가격 파일(174종 2,534행)을 받는다. 가장 빠르다.
2. Mcule 무료 계정을 만들고 토큰을 신청한다. 승인 시간이 걸린다.
3. 필요한 물질 수십 종만 수동으로 조회해 기록한다. 약관 위험이 가장 낮다.
4. 가격 기능을 비우고 자료를 구하지 못한 사실을 문서에 적는다.

어떤 경우에도 가격을 추정해 채우지 않는다.
