# 천연물 소재 후보의 합성 가능성과 공정 안전성 선별

작성 2026-11-04. 방향을 천연물로 전환하면서 정리한 기획 문서다. 측정값은
`evaluation/tool_benchmark_log.md`에 따로 쌓는다.

## 1. 개발 배경

### 1-1. NPDD.AI가 푸는 문제

NPDD.AI는 천연물 추출물의 LC-MS 데이터에서 **티로시나제·엘라스타아제·히알루로니다아제
억제제와 비슷한 골격을 가진 천연물**을 찾는다. 세 효소는 각각 미백과 주름개선에
해당한다. 목적은 그런 효과를 낼 수 있는, 아직 알려지지 않은 물질을 찾는 것이다.

팀이 정리한 억제제 데이터셋은 다음과 같다. 구조가 확인된 행만 센 것이다.

| 효소 | 전체 행 | 구조 있음 | IC50 있음 | 도킹 있음 |
|---|---|---|---|---|
| 티로시나제 | 3,858 | 3,619 | 3,619 | 754 |
| 엘라스타아제 | 10,331 | 10,254 | 2,868 | 0 |
| 히알루로니다아제 | 560 | 560 | 10 | 0 |

### 1-2. 거기서 비는 질문

추출물에서 찾은 천연물은 **그 추출물 안에 있는 것**이지 구할 수 있는 물질이 아니다.
소재로 쓰려면 양을 확보해야 하고, 추출은 수율이 낮고 원료 수급에 좌우된다. 그래서
합성으로 만들 수 있는지가 실제 문제가 된다.

그런데 이런 천연물은 대부분 **합성법이 알려져 있지 않다.** 활성이 좋아도 만들 수 없으면
소재가 되지 못한다. 만들 수 있어도 공정에 유전독성 물질이 들어가면 화장품 원료로 쓰기
어렵다. EU 화장품 규정은 발암성·변이원성·생식독성 물질을 금지한다.

정리하면 이 질문이 빈다.

> 찾은 천연물을 **합성으로 만들 수 있는가. 만들 수 있다면 그 경로가 깨끗한가.**

### 1-3. 이 소프트웨어의 자리

```
NPDD.AI                    이 소프트웨어
추출물 LC-MS               합성 경로 생성
  ↓                          ↓
억제제 골격을 닮은    →    만들 수 있는가
천연물 후보                 경로가 깨끗한가
                             ↓
                        소재화 가능한 후보
```

NPDD가 활성을 묻고, 이 소프트웨어가 제조 가능성과 공정 안전성을 묻는다.

## 2. 개발 과정

### 2-1. 처음 방향과 그 한계

처음에는 의약품을 대상으로 했다. 프로프라놀롤 같은 약을 입력하면 경로를 만들고 유전독성
물질이 쓰이는 경로를 걸러내는 구조였다. 이 부분은 작동한다.

그러나 의약품은 공정이 이미 확립돼 있다. 프로프라놀롤은 에피클로로하이드린을 쓰는
경로로 실제 생산되고 있다. 우리가 그 경로를 제외해도 현실을 바꾸지 못한다. 답이 이미
있는 질문이었다.

### 2-2. 중간에 잘못 짚은 것

천연물로 방향을 바꾼 뒤 처음 고른 후보가 Gallic acid, Caffeic acid, Benzoic acid
같은 물질이었다. 전부 **이미 상업적으로 판매되는 화합물**이다. 이런 물질에 "만들 수
있는가"를 묻는 것은 의미가 없다. 입력 분자만 바꾼 것이지 질문이 달라지지 않았다.

후보 선정 기준을 바꿨다. **구입 가능한 물질은 제외하고 구입 불가능한 것만 대상으로
한다.** AiZynthFinder가 재고 목록(ZINC)을 가지고 있어 이 판정을 자동으로 할 수 있다.

### 2-3. 확정한 선별 정책

경로에 등장하는 물질의 신호를 두 등급으로 나눈다. 모두 제외로 처리했을 때 프로프라놀롤
경로 10개 중 1개만 남았고, 부산물까지 넣으면 0개가 남았기 때문이다. 제시할 경로가 없으면
선별 도구가 아니다.

| 근거 | 처리 |
|---|---|
| ICH M7 목록 등재 물질 | 경로 제외 |
| 구조 경보 | 감점 |
| 모델 양성 | 감점 |
| 부산물에서 온 신호 | 감점 |

감점된 경로는 남기고 순위를 내린다. 화면에는 "1순위 · 신호 없음", "3순위 · 신호 2건"으로
표시한다. 이 구분은 주제 설계 문서의 filter 대 scorer 구분을 따른 것이다.

## 3. 사용하는 도구

### 3-1. 경로 생성

| 도구 | 역할 | 상태 |
|---|---|---|
| AiZynthFinder 4.4.1 | 역합성 경로 생성, 재고 판정 | 연동 완료, 실행 확인 |
| SynthEx | 전례 없는 구조의 경로 설계 | 무료 모델 어댑터 작업 중 |

AiZynthFinder는 특허 반응 기록을 학습한 템플릿 기반이다. 전례가 많은 구조에 강하고
전례가 없는 구조에 약하다. 천연물에서 경로를 못 찾는 경우를 SynthEx로 메울 수 있는지는
아직 확인하지 않았다.

원본 SynthEx는 유료 Gemini를 쓴다. 비용 때문에 OpenAI 형식 API를 쓰는 무료 공급자로도
돌아가도록 어댑터를 추가하고 있다. 원본의 에이전트 로직과 프롬프트는 수정하지 않는다.

### 3-2. 유전독성 판정

| 도구 | 방식 | 상태 |
|---|---|---|
| ICH M7 | ICH M7 목록 대조 + 구조 경보 | 연동 완료 |
| ADMET-AI 2.0.1 | Ames 데이터 학습 모델 | 연동 완료, 자동 실행 |
| Toxtree 3.1.0 | ISS 구조 경보 규칙 | 실행 확인, 미연동 |
| EPA TEST 5.1.2 | 여러 통계 방법 합의 | 실행 확인, 미연동 |

판정기는 설정으로 켜고 끌 수 있고 조합 규칙도 바꿀 수 있다. 조합은 하나라도 양성,
모두 일치, 다수결 세 가지다.

쓰지 않기로 한 도구와 이유는 `evaluation/tool_benchmark_log.md` 6절에 적었다. VEGA는
무인 자동 실행이 불가능하고, lazar는 유지보수가 끊겼고, OPERA는 Ames 엔드포인트가 없다.

### 3-3. 허용량

ICH M7(R2) Addendum의 요약 표에서 18종의 하루 허용량을 옮겼다. 값의 폭이 크다.
Bis(chloromethyl)ether가 0.004 µg/day이고 Formaldehyde가 10,000 µg/day다. 같은
양성 판정이라도 허용량이 250만 배 차이 난다.

출처 사본은 `논문/ICH_M7_R2_Addendum_FDA.pdf`에 보관했다.

### 3-4. 부산물

ASKCOS 공개 서버의 불순물 예측을 쓴다. 사용자가 버튼을 눌렀을 때만 구조가 전송된다.
프로프라놀롤 한 단계에서 후보 11개를 받았고 그중 7개에서 에폭사이드와 알킬 할라이드가
검출됐다. 경로에 적히지 않은 물질이다.

반응식의 원자 수지를 맞춰 **공동생성물도 도출한다.** 프로프라놀롤 단계에서 HCl이 나온다는
것을 계산으로 확인했다. AiZynthFinder는 계수도 공동생성물도 제공하지 않는다.

## 4. 평가 방법

### 4-1. 판정기 성능

이미 Ames 실험이 끝난 공개 데이터로 채점한다. 실험을 직접 하지 않는다.

평가 자료를 새로 구성했다. 기존에 쓰던 7,255개는 ADMET-AI의 학습 자료와 같아서 그
자료에서 채점하면 성적이 부풀려진다. MutagenLou2023에서 겹치는 구조를 제거해 3,091개를
남겼다. 10,045개 중 6,890개가 겹쳤다.

효과가 수치로 확인됐다. ADMET-AI는 0.851에서 0.768로 떨어졌고, 그 자료로 학습하지 않은
ICH M7 규칙은 0.651에서 0.679로 거의 변하지 않았다.

### 4-2. 경로 단위로는 따로 봐야 한다

물질 단위 성적을 경로에 그대로 쓸 수 없다. 경로 하나에 물질이 여러 개이고 한 물질이라도
걸리면 경로 전체가 빠지므로, 물질 단위 특이도가 경로에서는 거듭제곱으로 작용한다.
특이도 0.617에 물질 6개면 깨끗한 경로가 살아남을 확률이 약 5.5%다.

그래서 경로 단위 지표를 따로 측정한다. 남는 경로 수, 제외 비율, 신호 분포다.

## 5. 주장할 수 있는 수위

| 내용 | 근거 | 수위 |
|---|---|---|
| 공동생성물이 나온다 | 원자 보존 | 확정 |
| 하루 허용량 수치 | ICH M7 Addendum | 인용 |
| 판정기 정확도 | 공개 실험 데이터 3,091개 | 측정값 |
| 부산물 후보 | ASKCOS 예측 | 예측 |
| 경로가 실제로 성립한다 | 없음 | 주장하지 않음 |
| 이 물질이 안전하다 | 없음 | 주장하지 않음 |

마지막 두 줄을 지킨다. 경로 생성은 합성 가능성의 제안이지 실험으로 확인된 합성법이
아니다. 선별 결과는 신호의 유무이지 안전성 판정이 아니다.

## 6. 한계

- 실험을 하지 않는다. 모든 판정은 계산과 예측이다.
- AiZynthFinder가 경로를 못 찾는 것은 그 물질을 만들 수 없다는 뜻이 아니다. 탐색 범위와
  템플릿의 한계다.
- 재고 판정은 AiZynthFinder가 쓰는 ZINC 기준이며 실제 구매 가능성과 다를 수 있다.
- ICH M7은 의약품 불순물 지침이다. 화장품은 노출 경로와 규제 틀이 다르므로 같은 허용량을
  그대로 적용할 수 없다. 현재는 유전독성 신호의 유무를 보는 기준으로만 쓴다.
- 공개 Ames 자료끼리 겹침이 커서 평가 자료의 완전한 독립성은 보장되지 않는다.
- NPDD.AI는 아직 초기 단계이며 새 구조를 산출하기 전이다. 현재는 팀이 정리한 억제제
  데이터셋을 입력으로 쓴다.

## 6-2. 활성 예측 모델

팀이 정리한 티로시나제 억제제 자료로 분류 모델을 학습해 앱에 넣었다.

| 항목 | 값 |
|---|---|
| 학습 구조 | 824개 (활성 556 / 비활성 268) |
| 활성 기준 | AbTYR 효소, L-DOPA 기질, IC50 50 µM 이하 |
| 성능 | AUC 0.771, 균형 정확도 0.710 |
| 측정 방식 | 학습에 없던 골격을 통째로 빼고 시험 |
| 저장 위치 | `천연물/models/tyr_activity.joblib` |

값 자체를 예측하는 회귀는 같은 조건에서 R² 0.047로 쓸 수 없었다. 문헌 IC50은
실험실마다 크게 다르므로 수치 예측은 어렵고 등급 구분은 가능하다.

질량분석 피크는 구조를 주지 않으므로 분자식만으로 같은 판정을 시도해 보았다. AUC가
0.582로 거의 가려내지 못한다. 같은 분자식을 공유하는 구조가 많기 때문이다. 질량 기반
탐색에서 MS2로 구조를 좁히는 단계가 왜 필수인지를 보여주는 수치다.

## 7. 다음에 할 일

1. 구입 불가능한 천연물만 골라 경로 생성과 선별을 돌린다.
2. scaffold 계열별로 집계한다. 어느 골격이 합성 경로가 나오고 깨끗한지 본다.
3. 그 결과를 NPDD의 탐색 방향 선정에 넘긴다.
4. AiZynthFinder가 못 푸는 구조에 SynthEx 무료 모델이 쓸모 있는지 확인한다.
