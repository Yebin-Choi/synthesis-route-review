### 문헌 근거와 상보적 Ames 방법 조사

**파라세타몰의 제한된 정성 비교:** [2018년 출판사 초록·하이라이트](https://www.sciencedirect.com/science/article/pii/S0255270118302393)(DOI 10.1016/j.cep.2018.07.006)는 저자 공정에서 물 존재 시 form I·제품 순도 99%, 물 부재 시 4-acetoxyacetanilide가 주 생성물이라고 보고한다. 상세 실험법·수치 표는 확보하지 못했다. [PubChem CID 17499](https://pubchem.ncbi.nlm.nih.gov/compound/17499)의 구조는 문헌 후보 정체 확인용이지 로컬 생성의 관측 증거가 아니다.

**99% 순도는 분리수율도 특정 부산물 1%도 아니다.** 물 존재가 부산물 0의 음성 대조를 입증하지 않는다. 물의 양·온도·당량·농도·시간·완전한 제조법·개별 부산물 정량/검출한계가 없고 로컬 경로에도 대응 관측 조건이 없다. 조건 일치 제조법·음성 대조를 확보하기 전 자동 생성·정량 규칙이나 물 임계값을 만들지 않는다. 조건 누락은 미평가다. 근거: [문헌 비교·제한 기록](evaluation/results/paracetamol_byproduct_evidence.json).

**제품 범위:** 경로·조건·물질을 먼저 기록하고 실제 물질별 Ames 근거를 연결하는 설명 가능한 **사후 선별 연구 도구**다. SynthEx는 주 생성기로 유지하되 파일 가져오기 기록과 실제 LLM 생성을 구분하며, 후자는 접근 자격·어댑터 검증이 남아 있다. 실제 6경로는 AiZynthFinder 결과다. 실시간 생성 이벤트 기록·탐색 중 차단·일반 부산물 정량 예측은 미완료다. 투입량 화면은 수동 단일 반응, 코어는 명시 양론·수율의 다단계 DAG 계산이다.

## 1. 핵심 제안

|---|---|---|
| AiZynthFinder 독성 필터 | 코드와 과거 실행 기록 있음 | 기존 경로 평가의 기반 |
| 부산물 예측 | ASKCOS 호출 코드·과거 응답 있음 | 부산물 **후보** 수집. 현재 접속 재검증 필요 |
| 조건 KB | 회의 기록상 46개 반응 타입·약 38만 건 | 팀원 파일 확보 후 용매·시약 등 조건 후보 연결 |
| SynthEx | 소스 및 경로 수정 구조 확인 | 경로 제공 및 선택적 개선 실험 |
| Enamine·가격 자료 | 회의 기록에 수집 내역 있음 | 구매 가능성 확인. 가격 오류 정제는 별도 |

**이미 확보한 경로·코드·KB를 연결하는 것이 우선이며, 새 모델 학습은 필수 범위에서 제외한다.**

## 3. 구현할 흐름

**합성 경로 입력 → 조건 확인 → 부산물 후보 수집 → 물질별 위험 근거 확인 → 경로 비교**

- **조건:** 실제 문헌 조건과 KB 추천 조건을 구분한다. 모르면 ‘정보 없음’으로 둔다.
- **부산물:** 문헌 근거가 있는 제한된 생성 시나리오를 중심으로 하고, ASKCOS 예측은 보조로 사용한다.
- **위험 판정:** 알려진 우려 물질, 구조 경보, 조건부 생성 우려, 미평가를 구분한다.
- **경로 비교:** 동일한 후보 경로들을 평가해 위험 요소와 정보 부족을 함께 보여준다. 경보 미검출을 ‘안전’으로 표현하지 않는다.

**현재 사용 흐름:** 목표 선택·경로 준비 → 경로·단계 선택 → 구조와 누락 정보 확인 → 명시적으로 Ames 검사 실행 → 정책별 이유 비교 → 원본·평가 근거 JSON 내보내기. `needs_review`는 경보·불일치 등의 추가 검토, `insufficient_data`는 조건·구조·모델 근거 등의 부족, `excluded`는 선택한 연구 정책의 제외다. 대표 상태가 제외·검토여도 누락 사유는 남으며 `candidate`도 제한된 평가 범위의 후보일 뿐이다. 어느 상태도 안전성·실제 생성·ICH M7 판정이 아니다.

### 반드시 구분할 세 가지

| 질문 | 이번 연구의 범위 |
|---|---|
| 이 물질이 생길 수 있는가? | 조건·문헌·예측에 근거한 **후보 제시** |
| 이 물질에 변이원성 우려가 있는가? | 목록·구조 경보 등의 **근거 제시** |
| 최종 약에 위험한 양으로 남는가? | 실제 잔류량·정제 자료 없이는 **판정 불가** |

## 4. 보여줄 지표와 제외할 주장

**주요 지표:** 알려진 우려 물질 수, 구조 경보 물질 수, 조건부 경고 단계 수, 평가 가능 단계 비율, 미평가 단계 수, 합성 단계 수.

**보조 정보:** 출발물질 구매 가능 여부, 유사 반응의 수율 통계, 근거가 확인된 불순물 허용섭취량.

다음 표현은 사용하지 않는다.

- ‘부산물 종류가 적으므로 수율이 높다’ → 종류 수는 생성량·실험 수율이 아니다.
- ‘위험 점수 0.8이므로 독성 확률 80%’ → 현재 점수는 사람이 정한 가중치다.
- ‘허용섭취량을 계산했으므로 기준 충족’ → 실제 잔류량을 알아야 비교할 수 있다.
- ‘앞 단계에서 생기므로 정제 과정에서 제거된다’ → 경로 위치만으로 제거율을 알 수 없다.

## 5. 발표 전에 바로잡을 코드 문제

| 확인된 문제 | 필요한 조치 |
|---|---|
| 니트로사민에도 일반 TTC가 적용될 수 있음 | 특별 우려군은 개별 근거가 없으면 ‘한도 미산정·별도 평가 필요’ |
| 구조 경보가 없으면 ‘Class 5·제한 없음’으로 표시 | ‘현재 규칙에서 경보 미검출·등급 미확정’으로 변경 |
| 허용량 총합 계산에 물질 등급 구분 부족 | 적용 대상과 예외를 구분하거나 기능 제외 |
| 단계 위치 점수를 실제 제거 효과처럼 해석할 여지 | 연구용 우선순위 점수임을 명시 |

## 6. 제출 범위 제안

| 필수 | 여력이 있을 때 | 이번에는 제외 |
|---|---|---|
| 기존 경로와 조건 KB 연결 | SynthEx에 대안 수정 요청 후 재평가 | 모든 부산물의 완전 예측 |
| 제한된 불순물 시나리오 평가 | Enamine 구매 가능성 연결 | 무독성·규제 적합성 보장 |
| 위험 근거·미평가 범위 표시 | 근거 있는 수율 참고 통계 | 새 수율 모델 학습·최저 비용 최적화 |
| 문헌 사례·대조 사례·정보 누락 테스트 | 추가 타깃 비교 | 근거 없는 종합 안전 확률 |

Enamine은 **화합물 공급·주문 합성 회사**이며, 다운로드 가능한 Building Blocks 목록은 출발물질 구매 가능성 확인에 유용하다. 팀 자료에 이미 수집 기록이 있으므로 재사용을 우선한다. REAL 주문 합성 물질은 실제 재고와 구분한다.

## 7. 회의에서 결정할 세 가지

1. **연구 목표:** ‘안전 보장’이 아닌 ‘위험 초기 선별 및 대안 비교’에 동의하는가?
2. **필수 범위:** 기존 경로 평가를 먼저 완성하고, SynthEx 자동 수정은 추가 실험으로 둘 것인가?
3. **검증 대상·역할:** 어떤 문헌 사례와 대조 사례를 사용할지, 코드 수정·KB 연결·검증·발표를 누가 맡을 것인가?
