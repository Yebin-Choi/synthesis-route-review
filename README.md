# ReRx

목표 물질의 합성 경로를 찾고, 그 경로에 나오는 물질이 **변이원성 불순물**인지
도구 여러 개로 각각 확인하는 연구용 로컬 소프트웨어.

## 왜 도구를 여러 개 쓰나

ICH M7 가이드라인이 그렇게 하라고 적혀 있습니다. 식약처 번역본 원문입니다.

> 컴퓨터를 이용한 독성평가는 박테리아 변이원성시험의 결과를 예측하는 (Q)SAR 방법을
> 이용하여 실시하며 서로 보완적인 **2 종류의 (Q)SAR 예측 방법**을 이용한다.
> 첫째는 **전문적 경험 규칙에 기반한(expert rule-based)** 방법, 둘째는
> **통계에 기반한** 방법이다.

두 방법 모두 경고구조가 없어야 "변이원성 우려 없음"으로 봅니다. 하나라도 양성이면
허용 한계 수준 이하로 관리해야 합니다. 그래서 이 소프트웨어는 **판정을 하나로 합치지
않습니다.** 도구별 답을 나란히 놓고, 결론은 사용자가 냅니다.

| 방법 | 쓰는 도구 |
|---|---|
| 전문가 규칙 기반 | 전문가 규칙 (ICH M7), Toxtree 3.1.0 |
| 통계 기반 | 자체 모델 (지문·기술자), 자체 모델 (기술자), ADMET-AI 2.0.1, EPA TEST 5.1.2 |

## 실행

```powershell
.\start.bat
```

`py -3.11`이 필요합니다. 첫 실행 때 `.venv`를 만들고 패키지를 받습니다(인터넷 필요).
브라우저에서 <http://localhost:8501>이 열립니다. 끌 때는 검은 창에서 Ctrl+C.

경로 생성과 외부 도구는 별도 프로그램이 있어야 돌아갑니다(아래 *저장소에 없는 것*).
화면이 보인다고 그 기능이 준비됐다는 뜻은 아닙니다. 버튼이 "준비 중"이면 아직입니다.

## 쓰는 순서

1. **목표 물질**을 고르거나 SMILES를 직접 넣습니다.
2. **경로 생성**을 누릅니다. 몇십 초 걸립니다.
3. 경로 하나를 고르고, 탭 세 개를 봅니다.

| 탭 | 보는 것 |
|---|---|
| **위험 검토** | 그 경로의 모든 단계와 물질, 각 물질의 판정과 근거 |
| **도구 비교** | 같은 구조에 도구별 판정. 점수와 기준선 그림, 도구별 성능 |
| **부산물** | 버튼을 누른 요청만 ASKCOS로 보냄. 우려가 걸리면 제외가 아니라 감점 |

경로는 감점이 적은 순으로 놓습니다. 빠진 경로와 사유는 *제외 기준과 빠진 경로*에
있습니다. 결과는 *저장*에서 JSON·HTML·CSV로 받습니다.

경로 없이 물질 하나만 보려면 **독립 물질 검사**를 누릅니다.

## 화면에 나오는 말

ICH M7 식약처 번역본 표기를 그대로 씁니다.

| 말 | 뜻 |
|---|---|
| 양성 | 변이원성이 있다고 본 것 |
| 음성 | 변이원성이 없다고 본 것 |
| 경고구조 | 변이원성과 함께 나타나는 부분 구조 (structural alert) |
| 경고구조 없음 | 규칙에 걸린 구조가 없다는 뜻. **음성 예측이 아님** |
| 상충된 결과 | 적용 범위 안이지만 결론을 못 낸 것 |
| 예측 결과 없음 | 도구가 답을 내지 않았거나 실행이 실패한 것. **음성이 아님** |
| 적용 범위 밖 | 모델이 판단할 근거가 없는 구조 |

## 측정 성능

모델이 학습에서 한 번도 보지 않은 외부 검증셋 1,201종 기준입니다.
중간 수치는 `evaluation/tool_benchmark_log.md`에 다 있습니다.

| 도구 | 방법 | 기준선 | 균형 정확도 | 답한 비율 |
|---|---|---|---|---|
| 자체 모델 (지문·기술자) | 통계 기반 | 0.50 | 0.847 | 77.7% |
| 자체 모델 (기술자) | 통계 기반 | 0.50 | 0.789 | 100% |
| ADMET-AI 2.0.1 | 통계 기반 | 0.50 | 0.749 | 100% |
| Toxtree 3.1.0 | 전문가 규칙 기반 | — | 0.741 | 77.7% |
| EPA TEST 5.1.2 | 통계 기반 | 도구 자체 | 0.714 | 61.1% |
| 전문가 규칙 (ICH M7) | 전문가 규칙 기반 | — | 0.661 | 100% |

학습 자료의 양성 비율이 30.2%로 치우쳐 있는데, 이를 학습 가중치로 보정했습니다.
그래서 기준선을 선행연구가 쓰는 0.50에서 옮기지 않았습니다.

## 저장소에 없는 것

용량이 커서 뺐습니다. 받아서 바로 쓸 수 있는 것은 자체 모델과 전문가 규칙입니다.

| 없는 것 | 없으면 |
|---|---|
| `external_tools/` (AiZynthFinder, Toxtree, EPA TEST, 모델 실행 환경) | 경로 생성과 외부 도구 비교가 안 됨 |
| ADMET-AI 가중치 | ADMET 열이 "예측 결과 없음" |

EPA TEST를 쓰려면 설치 폴더를 환경 변수 `EPA_TEST_HOME`에 지정합니다.
지정하지 않으면 스크립트가 알리고 멈춥니다. 빈 결과를 0으로 내놓지 않습니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `app/` | 화면과 판정 로직. 진입점 `app.py` |
| `models/` | 학습된 joblib과 명세. `_balanced`가 쓰는 모델 |
| `data/ames/` | 학습·검증·시험 분할 |
| `ames/` | 모델 학습 스크립트와 결과 |
| `evaluation/tool_benchmark_log.md` | 측정 기록 원본 |
| `evaluation/` | 도구 실행·비교 스크립트, 측정 결과, 그림, 메모 |
| `test/` | 단위 검사 |
| `docs/` | 설계안, 제출 보고서 |

## 한계

- **안전성 판정 아님.** 경고구조가 없어도, 음성이 나와도 안전하다고 볼 수 없음.
- **Ames 하나만 봄.** ICH M7이 불순물에 요구하는 시험이 박테리아 변이원성 하나.
  유전독성의 나머지는 다루지 않음.
- 계산으로 찾은 경로는 실험으로 검증된 합성법이 아님.
- 점수는 확률이 아니라 순위용 숫자.
- 실패와 무응답은 미평가. 음성 아님.
- 부산물 후보는 예측. 얼마나 생기는지, 정제로 빠지는지 모르므로 제외 대신 감점만.
- ASKCOS로 보내면 반응물·생성물 구조가 외부 공개 서버로 나감.
- 화면의 예제 입력은 시험용.
