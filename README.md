# ReRx · 합성 경로 유전독성 검토

목표 물질의 합성 경로를 찾고, 경로에 나오는 물질의 AMES 변이원성 우려를 여러
도구로 각각 검토하는 연구용 로컬 소프트웨어.

도구 판정을 하나로 합치지 않음. 도구별 답을 나란히 두고 판단은 사용자 몫.

## 실행

```powershell
.\start.bat
```

`py -3.11` 필요. 첫 실행 때 `.venv` 생성과 패키지 설치(인터넷 필요).
브라우저에서 <http://localhost:8501>. 종료는 Ctrl+C.

경로 생성과 모델 추론에는 별도 모델 파일과 실행 환경 필요. 저장소에 없음.
화면이 보여도 그 기능이 준비됐다는 뜻은 아님.

## 화면

| 탭 | 내용 |
|---|---|
| 위험 검토 | 단계별 물질의 구조·역할, 제외·감점 사유 |
| 도구 비교 | 같은 구조에 대한 도구별 판정. 점수와 기준선, 도구별 균형 정확도 그림 |
| 부산물 | 버튼을 누른 요청만 ASKCOS로 전송. 우려가 걸리면 제외가 아니라 감점 |

경로는 감점 적은 순 정렬. 제외된 경로와 사유도 따로 표시.
결과는 JSON·HTML·CSV로 내려받기.

## 폴더

| 경로 | 내용 |
|---|---|
| `app/` | 화면과 판정 로직. 진입점 `app.py` |
| `models/` | 학습된 joblib과 명세. `_balanced`가 사용 중인 모델 |
| `data/ames/` | 학습·검증·시험 분할 |
| `ames/scripts/`, `ames/results/` | 모델 학습 스크립트와 결과 |
| `evaluation/tool_benchmark_log.md` | 측정 기록 원본 |
| `evaluation/scripts/` | 도구 실행·비교 스크립트 |
| `evaluation/results/`, `figures/`, `notes/`, `runs/` | 측정 결과, 그림, 메모, 실행 폴더 |
| `test/` | 단위 검사 |
| `docs/기획/`, `docs/보고서/` | 설계안, 제출 보고서 |
| `external_tools/` | 외부 프로그램과 별도 파이썬 환경. 저장소에 없음 |

## 측정 성능

모델이 학습 과정에서 보지 않은 독립 구조 기준. 중간값은 `tool_benchmark_log.md`.

| 도구 | 기준선 | 균형정확도 | 답한 비율 |
|---|---|---|---|
| 우리 모델 (XGBoost) | 0.50 | 0.847 | 77.7% |
| ADMET-AI 2.0.1 | 0.50 | 0.749 | 100% |
| Toxtree 3.1.0 | 규칙 | 0.741 | 77.7% |
| EPA TEST 5.1.2 | 도구 자체 | 0.714 | 61.1% |
| 자체 규칙 (ICH M7) | 규칙 | 0.661 | 100% |

학습 자료 양성 비율 30.2%. 이 치우침을 학습 가중치로 보정했으므로 기준선은
선행연구가 쓰는 0.50 그대로.

## 환경 변수

EPA TEST는 저장소에 없음. 설치 폴더를 `EPA_TEST_HOME`으로 지정.
미지정이면 스크립트가 알리고 중단. 빈 결과를 0으로 내놓지 않음.

## 검사

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s test -p "*_unit.py"
```

검사 전용 패키지 두 개가 더 필요함. `test/requirements.txt` 참고.

```powershell
.\.venv\Scripts\python.exe -m pip install -r test/requirements.txt
```

소프트웨어 점검이며 화학적 성능 검증이 아님. Windows에서만 확인.

## 한계

- 독성 판정 아님. 경보 없음이나 음성 예측은 안전하다는 뜻이 아님.
  AMES는 유전독성의 일부.
- 계산으로 찾은 경로는 실험으로 검증된 합성법이 아님.
- 점수는 보정된 확률이 아니라 순위 보조.
- 실패·무응답은 음성이 아니라 미평가.
- 부산물 후보는 예측. 생성량과 정제 제거 여부 미확인이라 제외 대신 감점만.
- ASKCOS 요청 시 반응물·생성물 구조가 외부 공개 서버로 전송됨.
- 화면의 예제 입력은 시험용.
